<h1 align="center">🧠 InterIA · Math Lab</h1>

<p align="center">Exploratory lab for analytic number theory,
spectral statistics, and λ-type invariants.</p>

---

## 🪶 About this lab

- Jupyter notebooks for Δ₃, λ, zeta zeros, mod-30 patterns, etc.
- Reproducible scripts in `src/`.
- Light reports in `reports/`.
- Public results via GitHub Pages (see Results Gallery).

For corporate style rules, see `STYLE_GUIDE.md` and `STYLE_GUIDE_FR.md`.

---

## 🧪 Structure

- `notebooks/` — experiments and exploration.
- `src/` — reusable functions and modules.
- `data/` — raw and processed datasets.
- `latex/` — notes or preprints using `interia-article.cls`.
- `pages/` — Results Gallery for GitHub Pages.
