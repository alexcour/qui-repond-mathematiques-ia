<h1 align="center">🧠 InterIA ·  Math Lab</h1>

<p align="center">Laboratoire exploratoire pour la théorie analytique des nombres,
les statistiques spectrales et les invariants de type λ.</p>

---

## 🪶 À propos de ce lab

- Notebooks Jupyter pour Δ₃, λ, zéros de ζ, patterns mod 30, etc.
- Scripts reproductibles dans `src/`.
- Rapports légers dans `reports/`.
- Résultats publics via GitHub Pages (voir Results Gallery).

Pour les règles de style, voir `STYLE_GUIDE.md` et `STYLE_GUIDE_FR.md`.

---

## 🧪 Structure

- `notebooks/` — expériences et exploration.
- `src/` — fonctions et modules réutilisables.
- `data/` — jeux de données brutes et traitées.
- `latex/` — notes ou preprints avec `interia-article.cls`.
- `pages/` — Results Gallery pour GitHub Pages.
