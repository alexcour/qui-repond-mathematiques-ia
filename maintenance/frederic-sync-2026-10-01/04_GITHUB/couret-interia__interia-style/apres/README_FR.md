# 🏛️ InterIA — Style & Templates (FR)

Ce dépôt contient le **style corporatif officiel**, les **templates**, et les
**structures de référence** utilisées dans tous les projets InterIA : cadres de preuve,
labs mathématiques, articles LaTeX, jeux de données, visualisations.

Il centralise :

- une identité visuelle commune (badges, entêtes),
- des templates de README (FR/EN),
- un STYLE_GUIDE complet (FR/EN),
- des structures de dépôt recommandées,
- des templates pour CI / Issues / PR / LaTeX,
- les conventions GitHub Pages.

C’est la **source de vérité** du style InterIA.

---

## 📘 Contenu du dépôt

```text

interia-style/
├── STYLE_GUIDE.md / STYLE_GUIDE_FR.md
├── templates/
├── examples/
├── .github/
└── LICENSE

```

### 🔹 `templates/`

Contient tous les fichiers **prêts à l’emploi** :

- README, README_FR, Hero FR/EN
- CONTRIBUTING, CODE_OF_CONDUCT
- issue templates, PR templates
- LaTeX class (`interia-article.template.cls`)
- GitHub Pages template (`index.template.html`)

### 🔹 `examples/`

Deux structures complètes :

- **interia_v1.2_repo_structure.md** — dépôt InterIA standard (EN)
- **interia_math_lab_structure.md** — lab mathématique (EN)

---

## ✨ Pourquoi ce dépôt ?

Pour garantir une **cohérence organisationnelle** entre tous les projets InterIA :

- documentation unifiée,
- workflows reproductibles,
- présentation professionnelle,
- facilité de contribution,
- harmonisation FR/EN.
