# 🏛️ InterIA Style — Hero (FR)

Page d’accueil élégante et corporate du dépôt **InterIA Style & Templates**.

Ce dépôt définit l’**identité visuelle**, les **standards de documentation** et les
**conventions de structure de dépôt** utilisées dans toute l’organisation InterIA.

> 🧮 **Statut :** officiel · reproductible · organisationnel

---

## ✨ Qu’est-ce qu’InterIA Style ?

InterIA Style fournit :

- des **templates de README** (EN/FR + Hero),
- le **guide de style** officiel (STYLE_GUIDE),
- des templates pour **CI**, **LaTeX**, **Issues**, **Pull Requests**,
- des **structures de dépôts** (InterIA v1.2, Math Lab),
- et les conventions GitHub Pages pour les **galleries de Résultats / Preuves**.

L’objectif est que **tous les dépôts InterIA partagent une cohérence absolue**.
