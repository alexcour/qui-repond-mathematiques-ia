# 🏛️ InterIA Style — Hero

A clean, corporate-style landing page for the **InterIA Style & Templates** repository.

This repository defines the **visual identity**, **documentation standards**, and
**repository structure conventions** used across the InterIA organization.

> 🧮 **Status:** official · reproducible · organization-wide

---

## ✨ What is InterIA Style?

InterIA Style provides:

- unified **README templates** (EN/FR + Hero),
- a corporate **STYLE_GUIDE**,
- drop-in **templates** for CI, LaTeX, Issues, PRs,
- reference **repository structures** (InterIA v1.2, Math Lab),
- and conventions for **GitHub Pages** / Results & Proof Galleries.

The goal is to ensure that **all InterIA repositories look and feel consistent**.
