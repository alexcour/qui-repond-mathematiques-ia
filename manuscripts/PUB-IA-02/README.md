## Journal-target readiness

Primary formatting target for this working draft: **Scientific Data — Data Descriptor**. The present manuscript already follows the journal's core Data Descriptor sequence (Abstract; Background & Summary; Methods; Data Records; optional Data Overview; Technical Validation; Usage Notes; Data Availability; Code Availability; References). No journal submission or acceptance is asserted.

Before any submission, the author must supply the required personal declarations. This repository deliberately does **not** infer author contributions, competing interests, funding status, or an ethics conclusion from repository history. The English and French drafts therefore contain explicit pre-submission placeholders for Author Contributions / Competing Interests / Funding. Under Scientific Data's active submission workflow, Author Contributions and Competing Interests may be captured in the submission system rather than duplicated in the manuscript; Funding still requires an accurate author-supplied statement.

The alternative **Data in Brief** route is not staged in this PR because it requires a substantive template conversion rather than a minimal structural patch, including its Specifications table and Value of the Data format. The frozen dataset itself remains unchanged.
