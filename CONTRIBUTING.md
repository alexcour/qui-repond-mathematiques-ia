# Contributing

Contributions are welcome when they address a **bounded, falsifiable and identifiable task**.

Good contributions include:

- reproducing a public certificate;
- identifying prior art;
- finding a counterexample or scope error;
- reporting a validator/data inconsistency;
- proposing an independent coding of a subset of events;
- improving documentation without changing claim status silently.

Please use one issue per object/question. Negative results and failed replications are valid contributions. A contribution to one object does not imply endorsement of the broader research program.

Do not attach or paste private correspondence or personal data into GitHub issues. Public issues must rely on public artifacts or redacted descriptions.
